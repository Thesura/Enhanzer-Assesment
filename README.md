# EnhanzerAssessment

# Angular App

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 22.2.6.

To install dependencies, run:

```bash
npm install
```

Then to run the app locally in development server, run:

```bash
npm start
```


# ASP.NET REST API

.NET Core SDK is required to run this project.

Then to run the app locally in development server, run:

```bash
dotnet run
```

# SQL Server Database

Restore the database using the dbscript.sql file in SQL Server Management Studio. SQL Server and SQL Server Management Studio is required.
